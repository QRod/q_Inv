# Capturas del producto

Capturas de q_Inv v0.5.0 generadas con una instancia temporal y datos ficticios. Las direcciones de los servidores pertenecen al bloque de documentación `192.0.2.0/24`; los nombres y cuentas usan el prefijo `demo-`. Los recursos y estados se generan como muestras de demostración.

La instancia no ejecuta el recolector SSH y el navegador bloquea solicitudes a destinos externos. Las imágenes no incluyen credenciales, claves, tokens, archivos RVTools reales ni datos de una instalación operativa. Son capturas directas de la interfaz, sin sustituir textos o valores de infraestructura real.
